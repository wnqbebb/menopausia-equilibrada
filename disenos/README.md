# Diseños originales

- `pausa/`: libro PAUSA, plantillas, kits y páginas de tienda.
- `menopausia-equilibrada/`: Guía Integral y 6 bonos.
- `marca/`: guía de marca (`BRAND.md`), reglas de diseño, descripción de cada imagen (`IMAGES.md`) y el mapa de imágenes (`blobs.json`).
- `fuentes/`: tipografías (Playfair Display, Poppins, Great Vibes, Silkscreen) para exportar sin internet.

Cada `.dc.html` es una página tamaño carta (794 × 1123 px). Ábrela con doble clic en el navegador para verla: las imágenes ya apuntan a `../../imagenes-soul/editadas/`.

Para editar, cambia el texto o el estilo en el HTML y vuelve a exportar los PDF (ver [`../docs/09-DISENOS-E-IMAGENES.md`](../docs/09-DISENOS-E-IMAGENES.md)).

Colores de la marca: rosa `#F7A8C7`, fucsia `#E0337A`, berry `#9B1B4F`, blush `#FCE4EC`, fondo `#FFF5F8`, tinta `#2B1B24`.
